QR Code Generator

A QR code turns a link, a piece of text, a Wi-Fi password or contact details into a pattern any phone camera can read in a second. This generator builds the code entirely in your browser — nothing is uploaded — and lets you adjust the error correction level, size and colours, then download it as PNG or SVG for print, posters, business cards or menus.

How to use the QR Code Generator

  1. Type or paste a link or any text into the box.
  2. Choose an error correction level and download size, and adjust the code and background colours if you like.
  3. Select “Download PNG” or “Download SVG” to save the code, and test it by pointing your phone camera at it.

Formula and method

A QR code stores data in a grid of black and white modules: Version 1 is 21×21 modules, each higher version adds 4 modules per side, up to Version 40 (177×177). The error correction level decides how much damage the code can survive and still scan: L recovers about 7%, M about 15%, Q about 25% and H about 30%. Higher levels hold less data; in byte mode, a Version 40 code at level L holds at most about 2,953 bytes.

Frequently asked questions

Is my content uploaded to a server?

No. Encoding happens entirely in your browser; the content never leaves your device.

Which error correction level should I choose?

M is the right default for most uses. Pick Q or H if the code will be printed where it can get damaged or covered, or if you plan to overlay a small logo. Pick L when your content is long and close to the capacity limit.

Does a QR code expire?

No. A static QR code bakes the content directly into the pattern, with no server involved, so a printed code works indefinitely — as long as the link it points to still works.

PNG or SVG — which should I download?

PNG is a bitmap, good for web pages and chats. SVG is vector, so it stays sharp at any size — the better choice for print, posters and business cards.
