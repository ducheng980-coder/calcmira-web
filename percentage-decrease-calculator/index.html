Percentage Decrease Calculator

When a price is cut or a metric falls, this tool shows the decrease as a percentage of the original value, with the absolute change for context.

Advertisement

How to use the Percentage Decrease Calculator

  1. Enter the original value.
  2. Enter the reduced value.
  3. Select “Calculate”.

Formula and method

Percentage change = ((new − original) ÷ |original|) × 100. A decrease shows as a negative percentage; if the value actually rose, the tool says so.

Example

Falling from 120 to 90 is a −25% change (a 25% decrease). Use the “Load example” button above to try it with the sample inputs.

Frequently asked questions

Is a 50% decrease followed by a 50% increase back to the start?

No. 100 → 50 is −50%, but 50 → 100 is +100%. Percentage changes are not symmetric because the base changes.

How is this different from a discount?

A discount starts from the percentage off; this tool starts from the two prices. The discount calculator works the other way round.
