Base64 Decoder

Received a Base64 string in a log, token payload or email header? Paste it here to decode it back to text. Malformed input is rejected with a plain-language error instead of silent garbage.

Advertisement

How to use the Base64 Decoder

  1. Paste the Base64 string.
  2. Select “Decode”.
  3. Copy the decoded text.

Formula and method

The string is validated against the Base64 alphabet, converted back to bytes, and decoded as UTF-8. Invalid UTF-8 byte sequences are reported as an error.

Example

SGVsbG8sIHdvcmxkIQ== decodes to “Hello, world!”. Use the “Load example” button above to try it with the sample inputs.

Frequently asked questions

Why did decoding fail?

Common causes: missing = padding, characters outside the Base64 alphabet (URL-safe variants use - and _ instead of + and /), or the decoded bytes are binary rather than text.

Can it decode a JWT?

A JWT’s header and payload are Base64URL, not plain Base64. Replace - with + and _ with / first, then decode each part.
