Percentage Increase Calculator

Prices, salaries, traffic, grades — when something grows, this tool expresses the growth as a percentage of the starting value, alongside the absolute change.

How to use the Percentage Increase Calculator

  1. Enter the starting (original) value.
  2. Enter the new value.
  3. Select “Calculate”.

Formula and method

Percentage increase = ((new − original) ÷ |original|) × 100. If the new value is smaller, the result is negative — the tool tells you it is actually a decrease.

Example

Going from 80 to 100 is a 25% increase. Use the “Load example” button above to try it with the sample inputs.

Frequently asked questions

Why divide by the starting value?

Percentage change is always relative to where you started. A rise from 80 to 100 (+20) is +25%; the reverse fall from 100 to 80 is −20%.

What if the starting value is zero?

Percentage change from zero is undefined (division by zero), so the tool asks for a different starting value.
